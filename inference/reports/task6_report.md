## 4. 해석
- 가장 좋은 Chronos: **chronos-bolt-tiny (과거 24시간)** — 60분 40.1ppm. 직접 학습한 GRU 14.8ppm(일정 포함) / 19.9ppm(일정 제외)와 비교.
- Chronos 는 CO₂ 과거값만 본다. 직접 학습 모델과의 차이 중 상당 부분은 **일정(미래 수업·예약)** 과 시간대 정보 때문이다: 과거 곡선만으로는 '9시에 수업이 시작된다'를 알 수 없어 상승 시작을 놓친다. 일정 제외 GRU 와의 차이가 순수한 '우리 데이터로 학습한 효과'에 가깝다.
- **zero-shot Chronos 는 60분에서 '현재값 유지'보다도 못하다.** 교실 CO₂ 는 수업 시작·쉬는 시간마다 톱니처럼 오르내리는데, 과거 곡선만 본 범용 모델은 '지금 오르는 중이니 계속 오른다'처럼 추세를 늘려 그리다가 쉬는 시간의 급락을 못 맞힌다.
- **과거를 길게 줄수록 좋아진다** (2시간 → 24시간: 60분 오차 약 50 → 40ppm). 24시간을 주면 '어제 이 시간에 올랐다'는 하루 주기를 볼 수 있기 때문이다.
- **예측 구간은 잘 맞는다**: 10~90% 구간 적중률이 대부분 78~83%로 이상적인 80%에 가깝다 → 값 자체보다 '불확실성의 크기'는 정직하게 말한다. 직접 학습한 GRU 는 한 값만 내므로 이런 구간 정보가 없다는 점은 Chronos 의 장점이다.
- tiny 와 small 의 정확도 차이가 거의 없다 → 보드에 올린다면 tiny(더 작고 빠름)가 낫다.
- **채택 의견 (초안)**: 학습 데이터가 거의 없는 초기(우리 실데이터 하루치)나 새 공간에는 바로 쓸 수 있는 좋은 출발점이다. 다만 일정 정보를 쓰는 직접 학습 모델보다 정확도가 낮고, 모델이 더 크고 느리며 같은 보드에 로컬 LLM 도 올려야 하므로 **상시 서비스의 기본 모델로는 채택하지 않고**, 데이터가 부족한 새 공간용 예비 모델로만 둔다.

## 5. 내 수집기 실데이터로 다시 비교 (2026-10-20 17:50 ~ 10-21 15:55, 22시간, 같은 230개 시점)
| 방법 | 5분 | 15분 | 30분 | 60분 CO₂ MAE (ppm) |
| --- | ---: | ---: | ---: | ---: |
| 현재값 유지 | 8.0 | 15.1 | 24.9 | 42.0 |
| 실데이터 학습 GRU (교육장 9/27~ 데이터로 학습) | 8.5 | 15.2 | 23.5 | 39.3 |
| **Chronos-Bolt tiny (학습 없음, 과거 최대 24시간)** | 10.0 | 15.0 | **22.1** | **36.0** |
| 10~90% 구간 적중률 (Chronos) | 82% | 83% | 82% | 78% |

- **합성 데이터와 결과가 뒤집혔다**: 합성(톱니 같은 수업 패턴)에서는 Chronos 가 가장 나빴지만, 실제 10월 교실(CO₂ 가 비교적 완만하게 오르내림)에서는 30·60분에서 Chronos 가 가장 좋다.
  범용 모델은 '완만한 추세를 이어 그리기'에 강하고, 합성 데이터의 급격한 쉬는 시간 급락 같은 패턴에 약하다.
- 예측 구간도 실데이터에서 여전히 80% 안팎으로 정직하다.
- **채택 의견 수정**: 학습 데이터가 거의 없는 지금(내 데이터 하루치)은 **Chronos-Bolt tiny 를 서비스 예측의 유력한 후보**로 본다.
  보드에서 한 번에 약 90ms·메모리 +68MB 라 공간 3개를 매분 예측해도 0.3초 수준으로 감당할 수 있다.
  다만 22시간·230개 시점은 표본이 작으므로, 데이터가 3주 쌓이면 직접 학습 모델과 다시 비교해 정한다. 일정 자료가 연결되면 일정을 쓰는 직접 학습 모델이 다시 앞설 가능성이 크다(합성 실험 근거).
