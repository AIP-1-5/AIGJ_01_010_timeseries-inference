# 과제 5. 상태 추정

> 측정 조건: 합성 데이터 5분 간격 · 학습 1~3주 · 검증 4주 · 시험 5주(고장 구간 제외) · 사용 여부는 직접 관찰 6일(8~19시)로 평가

## A. 사용 여부 추정 (사용중 / 비어있음)
- **정답 정의**: 학습 정답은 일정(수업 시간표·회의실 예약)으로 만든다. 일정은 결석·노쇼·연장·예약 없는 사용 때문에 실제와 다르므로, 직접 관찰한 6일로 평가한다.
- 일정 기반 정답이 직접 관찰과 일치하는 비율: **89.7%** (빈 방인데 일정상 '사용중'인 비율 1.5%)
- **입력에 일정 정보를 쓰지 않는다.** 정답을 일정에서 만들었는데 입력에도 넣으면, 모델은 센서를 보지 않고 일정을 그대로 베껴 학습 정답과 100% 가깝게 맞히는 척만 하고, 노쇼·예약 없는 사용 같은 진짜 차이는 하나도 못 잡는다.
- 입력: CO₂ 수준·5/15/30분 변화량, 온도·습도 변화량, 최근 6시간 최저 대비 CO₂, 시간대·요일, 공간
- **라운지** 는 일정이 없어 일정 기반 정답이 늘 '비어있음'이다 → 학습에서 빼고 '처음 보는 공간'으로 평가했다 (아래 공간별 표).

|                        |   정확도 |   F1 |   macro-F1 |   재현율 |   정밀도 |   빈 방→사용중 오판율 |
|:-----------------------|------:|-----:|-----------:|------:|------:|--------------:|
| 일정 기반 정답 (참고)          |  89.7 | 85   |       88.6 |  75.7 |  96.9 |           1.5 |
| 단순 규칙 (15분 CO₂ +30ppm) |  86.5 | 79.1 |       84.6 |  66.6 |  97.5 |           1.1 |
| 분류 모델 (센서만)            |  89.1 | 85.8 |       88.5 |  84.9 |  86.6 |           8.2 |

### 혼동 행렬 (분류 모델, 직접 관찰 기준)
| 실제 \ 예측 | 비어있음 | 사용중 |
| --- | ---: | ---: |
| 비어있음 | 1787 | 160 |
| 사용중 | 184 | 1037 |

### 공간별
| 공간   |   정확도 |   F1 |   빈 방→사용중 오판율 |
|:-----|------:|-----:|--------------:|
| 강의실1 |  87.4 | 90.5 |           1.8 |
| 강의실2 |  94.7 | 90.9 |           0.6 |
| 회의실  |  85.6 | 80.9 |          19   |
| 라운지  |  88.9 | 71.8 |           7.9 |

### 가장 많이 틀리는 상황
| 상황                   |   샘플 수 |   오류율(%) |
|:---------------------|-------:|---------:|
| 퇴실 후 20분 이내 (실제 빈 방) |    280 |     15   |
| 입실 후 15분 이내 (실제 사용중) |    210 |     19.5 |
| 그 외                  |   2705 |      9.9 |

- **퇴실 직후 빈 방이 '사용중'으로 오판되기 쉽다**: 사람이 나가도 CO₂ 는 환기 속도만큼 천천히 내려가 한동안 '사람이 있던 수준'에 머문다.
- **입실 직후는 '비어있음'으로 오판**: CO₂ 가 오르기 시작하는 데 몇 분이 걸린다 (센서 반응 지연 + 5분 평균).
- 큰 강의실에 적은 인원이 있으면 부피 대비 발생량이 작아 CO₂ 변화가 작다 → 구별이 어렵다. 작은 회의실은 2~3명도 잘 보인다.
- 냉난방 자동 제어에 쓰려면 '빈 방→사용중' 오판(빈 방에 냉방을 켜는 낭비)과 '사용중→빈 방' 오판(사람이 있는데 끄는 불편)의 비용이 다르므로, 끄는 결정은 '비어있음'이 15분 이상 이어질 때만 내리는 식으로 늦추는 것이 안전하다.

## B. 환기 선제 경보 (30분 안에 1,000ppm 초과 예상)
- **양성 정의**: 지금 CO₂ < 1,000ppm 이고 앞으로 30분(6칸) 안에 1,000ppm 이상이 되는 시점. 양성 비율 3.3%
- **이미 넘은 시점은 뺀다**: 넣으면 '지금 1,000 이상이면 경보'만 배워도 점수가 오르지만, 그건 '미리' 알리는 게 아니라 이미 늦은 경보다.
- **불균형**: 양성이 몇 % 뿐이라 '항상 경보 없음'만 해도 정확도가 90%를 넘는다 → 정확도는 의미가 없고 재현율·정밀도·macro-F1 로 본다.
- 입력: CO₂ 수준·변화량 + 시간대 + **앞으로의 일정 인원**(여기서는 써도 됨, 정답이 일정에서 오지 않으므로). 임계값 0.91 (검증 주 재현율 90% 기준)

|                   |   정확도 |   F1 |   macro-F1 |   재현율 |   정밀도 |
|:------------------|------:|-----:|-----------:|------:|------:|
| 모두 '경보 없음'        |  97.1 |  0   |       49.3 |   0   |   0   |
| 단순 규칙 (CO₂ ≥ 850) |  98.2 | 63.9 |       81.5 |  54.6 |  77   |
| 분류 모델             |  99.6 | 93.6 |       96.7 |  97.4 |  90.1 |

### 혼동 행렬 (분류 모델)
| 실제 \ 예측 | 경보 없음 | 곧 환기 필요 |
| --- | ---: | ---: |
| 경보 없음 | 6487 | 21 |
| 곧 환기 필요 | 5 | 191 |

- 결과: 재현율 **97.4%** (✅ 85% 이상), macro-F1 96.7 vs 단순 규칙 81.5 (✅ 규칙보다 높음)
- 정밀도가 낮으면(헛경보가 많으면) 사람들이 경보를 무시하게 된다. 다만 환기를 늦추는 비용(졸림·두통)이 헛경보로 창문을 한 번 여는 비용보다 크므로 **재현율을 우선**하고, 같은 공간에 15분 안에 다시 울리지 않게 묶어 체감 헛경보를 줄인다.
- 과제 3 예측 모델로도 '30분 뒤 예측값 ≥ 1,000' 으로 판단할 수 있다. 예측 모델은 값 전체를 맞히려다 보니 임계값 근처의 판단에는 분류기보다 둔할 수 있고, 분류기는 '넘느냐 안 넘느냐'에만 집중해 경계 근처를 더 잘 가른다. 서비스에서는 둘 다 계산해 하나라도 울리면 알리는 방식도 가능하다.
